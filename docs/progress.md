# kakao-agent 작업 현황

## 2026-10-22

### 구현

- Mac·Windows 모두 사용자가 카카오톡 화면에서 복사한 현재 클립보드만 읽는 자체 MCP로 바꿨다.
- 외부 backend, 카카오 DB 접근, 별도 수집 도구, 별도 실행 환경을 제거했다.
- 허용 목록 검사, 빈 클립보드·과도한 길이 차단, 연락처 일부 치환을 넣었다.
- MCP에는 `kakao_rooms`, `kakao_read`만 노출했다. 발송, 설정 변경, 자동화 생성은 넣지 않았다.

### 검증

- 자체 테스트: `uv run pytest -q`에서 20개 통과.
- 정적 검사: `uv run ruff check src tests` 통과.
- 배포 패키지: `uv build` 통과.
- GitHub Actions: macOS·Windows와 Python 3.11·3.13 조합 4개 행에서 설치, 테스트, 정적 검사를 실행한다.
- 실제 MCP subprocess로 도구 목록과 미허용 방의 클립보드 선차단을 확인한다.

### 남은 검증과 공개 기준

- Mac·Windows: 카카오톡에서 복사한 비민감 구간 하나를 `allow → read`로 실제 확인한다.
- 공개 전: 예제 설정·테스트 출력·Git 이력에 실제 방 이름, 대화, 키가 없는지 다시 검사한다.
- 자동화된 테스트는 카카오톡 앱의 실제 화면 복사와 개인 대화의 정확성을 보증하지 않는다.
