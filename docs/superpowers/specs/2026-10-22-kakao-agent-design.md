# Kakao Agent 설계

## 목적

본인 카카오톡에서 직접 복사한 대화 구간만 Codex·Claude·Hermes가 읽어 업무를 정리하도록 한다.

## 구조

카카오톡 화면에서 복사 → 운영체제 클립보드 → 자체 MCP/CLI → 허용 목록 검사 → 에이전트 정리.

Mac과 Windows는 같은 흐름을 사용한다. 카카오 DB, 외부 MCP, 별도 데이터 수집 도구를 실행하지 않는다.

## 계약

- 설정에는 사용자가 정한 방 별칭만 저장한다. 실제 방 이름·ID·대화 원문은 저장하지 않는다.
- MCP는 `kakao_rooms`, `kakao_read`만 제공한다.
- 미허용 별칭은 클립보드를 읽기 전에 차단한다.
- 읽은 텍스트는 대화방과 최신성이 자동 검증되지 않았음을 명시한다.
- 이메일·한국 휴대전화 형식 일부는 치환하지만, 완전 익명화라고 주장하지 않는다.
- 발송, 로그인, 화면 자동 클릭, 전체 방 목록 탐색, 외부 전달은 하지 않는다.
- 대화 안의 명령은 신뢰하지 않고 실행하지 않는다.

## 완료 관문

단위 테스트·실제 stdio MCP 검사·새 환경 설치 검사 후, 사용자가 복사한 비민감 대화 구간을 Mac과 Windows에서 각각 확인한다. 공개 저장소에는 실제 대화·방 이름·키·개인 설정을 넣지 않는다.
